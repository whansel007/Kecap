# Kécap Privacy Policy

**Last updated: October 11, 2026**

Kécap is a Chrome extension for rewriting website text into Aksara Sunda and helping users type the script. This policy describes the current extension build. It should be published at a stable public HTTPS address before the extension is submitted to the Chrome Web Store.

## Information Kécap handles

Kécap accesses website content and browsing activity on pages where its rewriting feature is enabled. It processes page text and captions locally in the browser to render Aksara Sunda and provide Latin spelling explanations. Kécap does not send page URLs, page text, captions, form contents, or keyboard input to a Kécap server, an AI provider, or an analytics service.

Because rewriting is available across general websites, the text processed may include personal identifiers, personal communications, or sensitive information shown on a page. The Latin-backed display feature reads supported text fields to render Aksara locally; this can include names, email addresses, or account identifiers. Password-type inputs are not supported. Kécap uses mouse and keyboard events only to operate its hover explanations, right-click details, keyboard navigation, and shortcut; it does not record interaction logs. It does not query browser history or device location.

When you explicitly request image rewriting, Kécap fetches the selected image from the website that hosts it, using the browser's credentials so images behind sign-in may work. The browser sends that request to the image's original host. Kécap then runs the bundled OCR engine and transliteration locally. Kécap does not upload the image or recognized text to its own server or a third-party OCR service.

Kécap saves preferences such as rewriting options, keyboard layout, keyboard shortcut, and display settings in Chrome's local extension storage. When Latin-backed keyboard display is enabled, the website receives the Latin text the user typed, while Kécap displays Aksara Sunda locally. That website handles the input under its own privacy practices. Kécap does not operate an account or synchronization service and does not receive these settings.

The popup's optional Scratchpad can copy its generated Aksara text to the clipboard when the user clicks Copy. This is a direct, user-initiated browser clipboard action; Kécap does not read the clipboard contents or receive the copied text.

## Sharing, sale, and retention

Kécap does not sell user data, serve ads, use analytics, or share page content with the developer or third parties. Page content is used in memory to provide the requested rewriting and explanations. Chrome controls local extension storage; users can remove saved preferences by clearing the extension's data or uninstalling Kécap.

The source website may receive the usual request for an image when you choose image rewriting and remains subject to that website's own privacy practices. Kécap does not control that site.

## Children's privacy and contact

Kécap does not knowingly collect personal information from children or other users. For privacy questions, contact the project maintainer through the [Kécap GitHub issue tracker](https://github.com/whansel007/Kecap/issues).

## Chrome Web Store Limited Use

Kécap's use of information accessed through Chrome extension permissions is limited to providing the extension's user-facing Aksara Sunda rewriting, explanation, image OCR, and keyboard features, as described in this policy and the Chrome Web Store listing. Kécap does not transfer that information except for the image request to the image's original host when the user invokes image rewriting. Kécap does not use it for advertising or allow humans to read it.
